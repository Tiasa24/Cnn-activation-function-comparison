# CNN Activation Function Comparison: Sigmoid vs ReLU

Comparative deep learning study evaluating **Sigmoid and ReLU activation functions** in CNN-based image classification using the **CIFAR-10 dataset**.

### Key Features

* Built and trained CNN models with Sigmoid and ReLU activations
* Compared **validation accuracy, loss and convergence**
* Analysed the impact of the **vanishing gradient problem**
* ReLU achieved **63.23% validation accuracy** vs **46.72% with Sigmoid**
* Evaluated model predictions on unseen test images

**Tech:** Python · TensorFlow/Keras · CNN · Deep Learning · CIFAR-10
